如何公开书目和笔记？

  1. 先在当前网页点 “添加书目”，把你看过的书都添加好。
  2. 点击下方 “下载 catalog.json”，它会把你的最新书单保存为书目文件。
  3. 打开你的 GitHub 仓库，把下载的 index.html 上传替换旧文件并 Commit，网站更新后所有人访问你的网站就能看到新书！
