如何让别人看到你新上传的书？

  1. 先在当前网页点 “上传新书”，把你看过的书都添加好。
  2. 点击下方 “下载最新 index.html”，它会把你的最新书单直接打包进网页文件。
  3. 打开你的 GitHub 仓库，把下载的 index.html 上传替换旧文件并 Commit，约 1 分钟后所有人访问你的网站就能看到新书！
